# kurator

Офлайновый разбор фотопарка: находит точные дубликаты, визуально похожие кадры
и тематические группы. Всё считается на твоей машине, сеть не используется.

| Слой | Что | Размер |
|------|-----|--------|
| Эмбеддинги | визуальная башня [SigLIP2 base, int8](https://huggingface.co/onnx-community/siglip2-base-patch16-224-ONNX) | 90 МБ |
| Рантайм | onnxruntime, CPU | — |
| Перцептивные хеши | pHash (DCT 32×32) + dHash, своя реализация на numpy | — |

Apache-2.0 на веса, MIT на код.

## Что он делает

- **Точные дубликаты** — по md5 байтов. Конфликтные копии `Имя (1).jpg`,
  перекачанные из Яндекс.Диска, дубли после переноса между устройствами.
- **Near-дубликаты** — тот же кадр в другом качестве JPEG, после ресайза или
  мелкой правки. Находятся пересечением pHash и косинуса эмбеддинга.
- **Burst-серии** — `Имя (0).jpg`, `Имя (1).jpg` и кадры с одинаковым EXIF в
  пределах двух секунд. **Показываются, но никогда не переносятся автоматически**:
  это альтернативные кадры одного момента, а не мусор.
- **Кластеры** — визуальные группы по эмбеддингам, без запроса: «всё это про
  одно и то же». Снимок попадает в группу только если похож на её центроид,
  поэтому цепочки A~B~C не сливают всё в один ком.
- **Отчёт** — markdown + html + контакт-листы с превью, где оригинал помечен
  жёлтой рамкой, а кандидат — красным.

## Чего он не делает

**Не удаляет ничего.** Файлы только переезжают в `<корень>/_kurator_quarantine/`
с манифестом, откат — `kurator undo`. Никакого `rm`.

## Установка

```bash
git clone https://github.com/Omen4Dead/kurator.git
cd kurator

# окружение: uv + Python 3.11+
curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync

# веса (90 МБ, единственный обращающийся к сети момент)
./scripts/pull-model.sh
```

Проверить:

```bash
uv run kurator models
```

## Использование

```bash
# индекс: обойти папку, посчитать хеши и эмбеддинги
uv run kurator index ~/Pictures

# что нашли
uv run kurator stats ~/Pictures
uv run kurator dups ~/Pictures
uv run kurator clusters ~/Pictures

# подобрать пороги под свой архив
uv run kurator calibrate ~/Pictures

# отчёт с превью
uv run kurator report ~/Pictures
open ~/Pictures/out/report.html

# интерфейс в браузере (локально, 127.0.0.1)
uv run kurator ui ~/Pictures

# перенос кандидатов — сначала посмотреть, потом сделать
uv run kurator apply ~/Pictures --dry-run
uv run kurator apply ~/Pictures --yes
uv run kurator undo ~/Pictures --yes
```

Повторный `index` инкрементальный: файлы с неизменным размером и mtime
пропускаются. Чтобы пересчитать всё — `index --rehash`.

### Пороги

`pHash ≤ 6` и `cosine ≥ 0.90` — дефолты, а не истина. Они разумны на обычных
фотографиях, но подбирать их надо на своём архиве: `kurator calibrate` печатает
распределение расстояний и сколько групп выйдет при разных порогах.

```bash
uv run kurator dups ~/Pictures --phash 4 --cosine 0.95
```

Флаги `--phash` и `--cosine` есть у `dups`, `report`, `apply` и веб-UI.

## Как устроено

```
src/kurator/
  config.py     пути, константы, пороги
  hashing.py    md5, pHash (DCT), dHash, хамминг на numpy
  imaging.py    EXIF, препроцессинг 224×224 под SigLIP
  encoder.py    сессия onnxruntime, батчинг
  indexer.py    обход папки, инкрементальность
  db.py         SQLite-индекс (по одному файлу рядом с фото)
  dedupe.py     exact / near / burst, выбор «оставляю»
  cluster.py    leader-кластеризация по центроидам
  quarantine.py перенос + манифест + откат
  contact.py    контакт-листы
  report.py     markdown и html
  web/          локальный HTTP-сервер и одностраничный UI
```

Индекс лежит в `<корень>/.kurator/index.db` и переезжает вместе с фотками.
Эмбеддинги хранятся как `float32`-блобы: 768 чисел на снимок, ~3 КБ.

## Безопасность

- Сетевого кода в рантайме нет вообще. `pull-model.sh` — единственное
  обращение наружу, и хеш файла сверяется с зашитым в скрипте sha256.
- Веб-интерфейс слушает только `127.0.0.1` и требует сессионный токен, чтобы
  случайная страница из браузера не обратилась к локальному серверу.
- Отдача превью проверяет, что путь не выходит за пределы корня.

## Тесты

```bash
uv run pytest -q
```

Плюс грязный синтетический архив для ручной проверки всего пайплайна:

```bash
uv run python scripts/make_testset.py /tmp/kurator-test 180
uv run kurator index /tmp/kurator-test
```

Генератор кладёт туда точные дубли, near-дубли разного качества, burst-серии,
битые jpeg, файлы без EXIF и не-картинки.

## Android

Модуль `android/` — нативный Kotlin: тот же файл весов и тот же набор правил,
но без numpy и Pillow (ONNX Runtime Mobile + `Bitmap`). Общие с десктопом —
модель, правила дедупа и пороги.
